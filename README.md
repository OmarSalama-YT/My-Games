
## التقنيات المستخدمة
- **HTML5 Canvas** - لرسم المشهد والرسومات
- **JavaScript (Vanilla)** - لمنطق اللعبة والفيزياء
- **CSS3** - للتصميم والواجهة
- **RequestAnimationFrame** - لحلقة اللعبة السلسة
- **Touch Events API** - لدعم اللمس
- **Mouse Events API** - لدعم الفأرة

## المتطلبات
- أي متصفح حديث (Chrome, Firefox, Safari, Edge)
- لا يحتاج إلى أي مكتبات خارجية
- لا يحتاج إلى إنترنت (يعمل Offline)

## التثبيت والتشغيل
1. حمّل ملف `index.html`
2. افتحه في أي متصفح
3. ابدأ اللعب مباشرة!
